# 清洁室独立功能规格（原创实现依据）

> 这是「干净室（clean-room）」的核心产物：把参考 App 抽象成**与其素材/代码/商标完全脱钩的独立功能规格**，后续所有实现只依据本文档，不回看参考素材。
> 本文档刻意**不使用**参考 App 的商标、游戏名、活动名、专有文案、专有模块名，全部改用本项目原创命名。

---

## 0. 清洁室规则（落到执行）

**允许**：参考"功能层级、交互密度、信息架构、节奏、模块完整度"作为成熟度标尺。
**禁止**：复制图片/音频/字体/动画/prefab/代码；导入参考素材；使用其商标/游戏名/活动名/专有文案；逐像素还原；反编译复用逻辑。
**方法**：参考结构 → 抽象成"能力需求 + 密度目标" → 用原创程序化/AI 原创素材实现。

**密度目标 ≠ 素材数量**：参考包 20 套牌皮是"该有皮肤体系"的信号，不是"必须做 20 套"的指标。我们用 **CSS/Canvas 程序化生成**满足体系完整度，避免 320MB 膨胀。

## 3. 设计系统（原创）

参考包的"深色舞台 + 聚光 + 发光牌桌 + 漂浮筹码 + 星尘 + 纵深"是**通用赌场舞台美学**（不可版权化的风格类别）。我们据此**原创**一套：

- **方向**：竖屏优先（9:19.5 安全区适配，已处理刘海/灵动岛）。
- **色彩 token**：深绿/木纹边 + 金色高光（CSS 变量 `--felt / --gold / --frame / --scene-bg`）。
- **字体**：系统字体 + 可商用字体，不用参考字体。
- **动效语言**：CSS/Canvas 程序化（赢牌闪光、筹码飞行、连胜烈焰按牌型分级、座驾横移），帧目标 60fps。
- **音频**：WebAudio 合成 + edge-tts 原创方言语音包（已自产 180 条），不用参考音频。
- **信息架构**：三屏（大厅 / 选桌 / 牌桌）+ 模态面板系统（`openPanel`）承载所有成长/运营/社交/安全模块。

## 4. 子系统功能规格（抽象需求，非素材清单）

每条给出：**能力 / 密度目标 / 本地化处理 / 验收**。

### 4.1 牌桌核心（最高优先）
- 能力：N 人桌、盲注/前注、边池、摊牌、最优 5 张评定、动作（弃/过/跟/加/全下）。
- 密度目标：行动音 6 种、发牌/筹码音、赢家展示、牌型特效分级。
- 验收：35 万手压测 0 崩溃、筹码守恒（已达成）。

### 4.2 牌局复盘 + 错误分析（超越点 ①）
- 能力：每手记录公共牌/手牌/对手摊牌/每个决策当下胜率与底池赔率，判定对错（价值/偏误/诈唬/合理弃牌）并给理由；列表 + 详情 + 整体决策正确率。
- 密度目标：滚动保留近 N 手；牌局编号（安全/申诉基础）。
- 本地化：纯本地持久化。
- 验收：决策判定与蒙特卡洛胜率一致；列表/详情可点开（**已实装**）。

### 4.3 实时策略提示（超越点 ②，待建）
- 能力：行动前给"标准范围/赔率"提示，标记偏离；可开关（训练模式/考试模式）。
- 验收：提示与 equity 引擎一致；可关闭以测真实水平。

### 4.4 AI 对手画像（超越点 ③，待建）
- 能力：每个 AI 显示风格标签（紧凶/松凶/跟注站/鲨鱼）+ 你对其历史胜负；难度分层（休闲/高手/大师）。
- 现状：已有自适应 AI（蒙特卡洛 + 对手建模剥削），缺"画像展示层"。

### 4.5 连胜烈焰 / 情绪反馈
- 能力：连胜阶梯式特效升级；牌型越大特效越强；赢牌庆祝。
- 密度目标：≥5 级阶梯（程序化粒子/震屏/震动）。
- 验收：CSS/Canvas 实现，无大资源（已部分达成）。

### 4.6 桌面社交（快捷语 + 表情 + 礼物）
- 能力：预设快捷语气泡（原创短语库）、表情、互动礼物 CSS 动效。
- 本地化：单机版对 AI 发，多人版广播。
- 现状：入口在、动效待实装。

### 4.7 入场座驾秀
- 能力：进桌按已装备座驾播放原创横移/入场动效 + 合成音。
- 现状：已有 emoji 座驾 + driveAcross 动效，可升级为原创 SVG/Canvas。

### 4.8 成长体系（赛季 / 段位 / 成就 / 任务 / 等级）
- 能力：等级经验、段位、赛季进度与奖励表、成就解锁与领取、每日任务领取。
- 现状：等级/经验/任务/成就**可领取已实装**；赛季奖励表、段位晋升动画待实装。

### 4.9 运营（全部免费训练化）
- 签到 / 转盘 / 兑换码 / 限时礼架 / 里程碑奖励：均发训练筹码，无真钱。
- 现状：签到/转盘/兑换码已实装；礼架/里程碑为展示，待发奖实装。

### 4.10 外观体系
- 牌皮 / 桌布 / 头像框 / 称号 / 座驾 / 手表 / 场景 / 牌背：原创程序化或 AI 原创。
- 现状：商店 9 类已实装（程序化皮肤 + 少量原创图）。

### 4.11 安全 / 公平（本地版）
- 牌局编号（已随复盘加入）、行动日志（复盘即日志）、回放（复盘详情）、举报入口（多人版）。
- 本地版无需账号风控；多人版再接。

### 4.12 工程分层（可维护性硬要求）
规则 `poker.js` / 状态机 `game.js` / AI `ai.js` / 持久化 `store.js` / 皮肤 `skins.js` / 音频 `sound.js`+`music.js`+`voice.js` / 动效 `fx.js` / UI 控制 `ui.js` / 多人 `mp.js`+`online.js`。
要求：各层职责单一、UI 不写规则、规则不依赖 DOM。
