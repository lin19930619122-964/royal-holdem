# 升级路线图（清洁室 / 分层 / 优先级驱动）

> 依据 `gap-matrix.md` 的优先级，制定分阶段、可验收、守约束的升级路线。
> 每阶段独立交付、独立测试、独立可回传 IPA。每阶段先动**数据/规则/状态层**，再动 **UI/动效层**，保持分层。

---

## 0. 贯穿全程的护栏

- **约束**（不可破）：不接真钱/充值/提现/广告；本地训练筹码；本地持久化；不采集；体积红线（CSS/Canvas 优先）；内容得体。
- **清洁室**：只依据 `reference-cleanroom-abstraction.md`；不复制参考素材/代码/商标。
- **分层**：规则不碰 DOM；UI 不写规则；新系统先建 store/规则 API 再接 UI。
- **质量门**：每阶段 jsdom 测试全绿 + 语法检查 + 本地服务 200，再 push 触发云构建。
- **体积门**：每阶段构建后核对 IPA 体积不异常增长（当前 56M 基线）。

---

## 阶段 1 — 牌桌社交与情绪反馈（差距 B + A 第一梯队）

**目标**：让牌桌"活"起来——能交流、有礼物、连胜有层次。

- 1.1 数据层：原创快捷语短语库（中文，分类：挑衅/赞美/认怂/惊讶/催促），`store` 记录最近用语。
- 1.2 UI：座位上方快捷语气泡（CSS 出现/淡出），单机对 AI 触发、多人广播。
- 1.3 互动礼物：原创礼物集（程序化 SVG/emoji 组合）+ 命中 CSS 动效（飞行/爆开）+ WebAudio 合成命中音。
- 1.4 连胜烈焰阶梯：≥5 级（按连胜数/牌型升级粒子、震屏、震动），纯 Canvas/CSS。
- **验收**：气泡/礼物/烈焰在 jsdom 渲染测试可触发；无新增大资源；牌桌交互节奏顺。

## 阶段 2 — 训练超越项（差距 G，本项目差异化核心）

**目标**：把"能打"升级为"能教"，超过参考。

- 2.1 实时策略提示：行动前显示简化标准范围（位置×牌力）+ 底池赔率门槛 + 偏离标记；可开关（训练/考试模式）。复用 `ai.js` equity。
- 2.2 AI 对手画像：为每个 AI 计算并展示风格标签（紧凶/松凶/跟注站/鲨鱼）+ 你对其历史胜负；接 `OppModel` 与 `store`。
- 2.3 盈利曲线：基于已存 `handLog` 净收益绘制近 N 手曲线（Canvas）。
- **验收**：提示与 equity 一致且可关闭；画像标签随样本更新；曲线与复盘数据一致。

## 阶段 3 — 大厅成长实装（差距 C 第一梯队）

**目标**：把最重的成长模块从占位变真实。

- 3.1 赛季体系：数据层赛季等级/经验/赛季 ID + **奖励表（免费档）** + 领取 + 重置；UI 赛季页 + 晋升动画。
- 3.2 段位成长：段位阈值 + 晋升/掉段 + 段位展示（牌桌/资料）。
- 3.3 成就墙展示：现有成就数据 → 墙式网格 + 解锁翻牌动画。
- 3.4 通行证：免费任务线 + 奖励表 + 领取。
- **验收**：奖励发放走 store 原子操作；领取幂等；重置按本地日期。

## 阶段 4 — 外观与开屏精致度（差距 E + F 第二梯队）

- 4.1 牌皮/桌布主题扩展：再增若干**原创程序化**主题（含大/小/宽屏自适应，CSS 变量驱动）。
- 4.2 原创开屏：深色舞台 + 聚光 + 漂浮筹码/牌 + 星尘（Canvas 粒子，纯程序化，无大图）。
- 4.3 入场座驾秀升级：原创 SVG/Canvas 座驾横移 + 合成音。
- **验收**：主题切换即时；开屏 60fps；体积不超红线。

## 阶段 5 — 运营补全与社交外延（差距 C/D 第三梯队）

- 5.1 限时礼架 / 里程碑奖励 / 活动中心：轮换 + 触发发奖（训练筹码）。
- 5.2 排行/邮件/俱乐部：本地化数据 + 发奖；多人版接服务端。
- 5.3 旁观/换桌/举报：多人版接入。
- **验收**：均免费；无真钱路径；多人项依赖服务端的明确标注。

## 阶段 6 — 工程重构与回归（贯穿，阶段末集中）

- 6.1 拆 `ui.js`（1,332 行）：按"面板渲染 / 牌桌渲染 / 输入控制 / 复盘"拆模块。
- 6.2 抽象面板注册表：`openPanel` 改为数据驱动注册，减少分支。
- 6.3 回归测试扩充：引擎压测 + AI 基线 + 各面板渲染 + 复盘判定。
- **验收**：行为不变；测试覆盖增加；分层更清晰。

## 里程碑与顺序建议

| 里程碑 | 含阶段 | 价值 |
|---|---|---|
| M1 牌桌活起来 | 1 | 情绪价值、社交感 |
| M2 训练超越 | 2 | 差异化、训练价值（核心卖点） |
| M3 成长成熟 | 3 | 大厅密度对齐参考 |
| M4 视觉精致 | 4 | 华丽度 |
| M5 运营补全 | 5 | 完整度 |
| M6 工程健壮 | 6 | 可维护性 |

> 建议执行序：**M1 → M2 → M3 → M4 → M5**，M6 穿插在每个里程碑末做小步重构。
> 复盘+错误分析（超越点①）已在 M2 之前完成并上线。
